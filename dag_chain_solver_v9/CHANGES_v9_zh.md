# v9 0.9.0 修改說明

日期：2026-10-31。從v8 0.8.1複製到獨立v9目錄；v8檔案與原始結果保持不變。

- 新增搬運主導的鏈覆蓋與有界低成本切邊，原始DAG依賴保持完整。
- 同時嘗試保守footprint限制與不以Tensor聯集大小硬切的候選，因為同核群組不代表全部資料同時存活。
- 入選候選可先經有界重排修復搬運，再檢查最終非退步條件。
- 同核鏈段只約束分配，不強制連續執行；仍使用完整DAG-ready排程及critical／DFS順序候選。
- 新版候選攜帶內部placement_group約束，後續移核必須帶上整組及writer閉包。
- 保留完整v8結果作為入口候選；新增分組方案經估價與精確搬運檢查，cycles優先選優。
- 新增集中可調的communication_*配額與communication_stats診斷，維持正式CLI與JSON格式。
- 使用未修改的官方評分器比較2／3／4／5核各10組，保留所有結果與退步；測試報告在reports/RESULTS_V9_zh.md。

完整官方Step3仍未移植；內部估計不退步並不等於官方cycles保證。正式結果必須以官方評分器為準。
