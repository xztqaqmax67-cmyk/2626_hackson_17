# v5 修改摘要

以 v4 0.4.0 為基底獨立建立 0.5.0，沒有覆寫 v4。原檔案雜湊見
`reports/v4_preservation_manifest.json`；使用者提供的 50 筆結果原樣保存為
`reports/v4_results_1_to_5_baseline.json`。

新增兩種通用候選：加權拓撲深度粗階段中自然連通塊的核心配額枚舉、按消費者等待餘量搬移完整 writer 群組。
所有原始依賴仍保留；分層不引入屏障；每個候選都重新在全圖排程與估價。

保留完整 v4 搜尋和事件估價最佳方案，再處理新候選。測試 API 可以單獨停用兩種候選，
方便檢查來源與比較；正式 CLI 不增加調參選項。

一般合法性測試包含人工分叉匯合、跨階段依賴、共享輸入、多寫入者、容量門檻、零 cycles，
以及固定種子隨機 DAG 和 ID 重編。測試不讀取公開用例的最佳分配或最佳 cycles。
正式評分的 2～5 核重新產生；1 核沿用相同新版原評分器的基準並核對來源雜湊。

詳細流程與限制見 README；結果見 `reports/RESULTS_1_TO_5_CORES_zh.md`。

## 本次驗證

- MSVC／MinGW 各 6/6 C++ 套件、CLI 契約和 26/26 輸入契約通過。
- 64/64 合成 DAG 官方驗證、40/40 公開測試官方驗證通過。
- 公開用例 40 組重複生成一致；4 組跨編譯器一致。
- 對 5 組變更方案及 4 組均勻抽取對照，停用新增策略可重現 v4 原方案；只正規化診斷程式的 CRLF/LF。
- 平均排程加速比 1.909483× → 1.914700×；40 組 cycles 合計 144,335,197 → 143,606,031。
- 總 COPY 7,235,510,848 → 7,141,261,632 bytes；5 組 cycles 降低，35 組相同，沒有增加。
- 自寫估價與官方 cycles 的平均絕對誤差約 0.730%，故仍不宣稱官方效果可由估價完全保證。

源碼在正式公開評分前固定，沒有依評分結果調整區域／slack 參數。
